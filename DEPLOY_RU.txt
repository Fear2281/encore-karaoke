ENCORE. УСТАНОВКА В БАРЕ

Понадобятся сервер с Ubuntu 24.04 LTS, SSH-доступ, публичный IP и домен.
Один сервер обслуживает сайт, пульт и все 12 столиков.

1. Домен и сеть

В DNS создайте A-запись домена, например karaoke.example.com, на публичный IPv4
сервера. Добавляйте AAAA только при рабочем IPv6. Откройте входящие TCP 80 и 443
в панели провайдера и на сервере, оставьте доступ к вашему SSH-порту.
Подождите, пока DNS начнёт возвращать адрес сервера.

2. Docker

Подключитесь к серверу. Установите Docker Engine и плагин Docker Compose
из официального APT-репозитория для Ubuntu.
Инструкция: https://docs.docker.com/engine/install/ubuntu/

Проверьте:
  sudo docker version
  sudo docker compose version

3. Файлы и настройки

Клонируйте репозиторий на сервер. Войдите на сервер по SSH, затем выполните
команды из README.md. Для приватного репозитория нужен доступ на чтение.

  cp .env.example .env
  chmod 600 .env
  nano .env

Укажите в DOMAIN свой домен без https:// и без пути. В ENCORE_DJ_PASSWORD
задайте свой длинный пароль. ENCORE_VK_TOKEN заполните, если VK предоставил
токен с доступом к audio.search, audio.getById и воспроизводимым потокам.
Токен используется только на сервере. Без токена Encore показывает «Россия:
Топ-100» по публичному снимку UpSound AI и ищет по этому списку. Снимок с датой
поставляется с приложением. Сервер проверяет обновления каждые 10 минут.
Главная показывает первые 20 позиций и проверяет список раз в минуту.
Трек из чарта можно заказать без файла. Гостям вход в VK не нужен.

Поиск на главной использует российскую витрину iTunes. Ключ и вход
не нужны. Во вкладке «Своя музыка» можно отправить название песни
и исполнителя. В общей очереди столики чередуются. Заявки одного
столика идут по времени подачи.

4. Запуск

  sudo docker compose config --quiet
  sudo docker compose up -d --build
  sudo docker compose ps
  sudo docker compose logs --tail=100 app caddy

Caddy получает и продлевает сертификат HTTPS автоматически:
https://caddyserver.com/docs/automatic-https

Затем откройте https://ВАШ-ДОМЕН/api/health. Ожидается status=ok, modules=5.
Откройте сайт, войдите в «Пульт диджея» со своим паролем и отправьте с телефона
пробную заявку. Одобрите её и нажмите «На сцену», чтобы запустить таймер.
Звук для выступления включается отдельно.

5. QR для столиков

В пульте откройте «QR-карточки» и нажмите QR рядом с каждым столиком.
Скачайте SVG или распечатайте карточку с номером. Сканирование должно открыть
домен бара и автоматически подключить нужный столик. Для подключения другого
столика гость сначала завершает текущий визит. Проверьте первый и последний
столики камерой телефона через мобильный интернет, затем разложите карточки.
Коды, созданные с адресом 127.0.0.1, работают только на компьютере с Encore.

6. Закрытие визита и данные

Гость нажимает «Завершить визит», либо сотрудник нажимает «Закрыть визиты»
рядом со столиком после ухода гостей. Таймер автоматически закроет визит через
4 часа с момента открытия. Новый посетитель с другого браузера получает
собственную историю сразу, даже если предыдущий визит ещё не закрыт.
Приложение снимает активные заявки закрытого визита и удаляет его избранное.
После закрытия новый визит начинается с пустой истории.

На сервере сохраняются:
  /data/state.json — столики, настройки, открытые визиты, сведения о треках
  и журнал заявок. Журнал видит диджей. По завершённым трекам VK считается топ
  за 7 дней. После закрытия визита запись о заявке остаётся для отчёта.
  /data/keys/ — ключи входа в пульт.

Данные находятся в томе Docker encore-data. На Windows те же файлы лежат
в App_Data. Токен VK и пароль задаются в .env на сервере.

7. Обновления и резервная копия

Для резервной копии в период, когда бар закрыт:
  cd ~/encore
  sudo docker compose stop app
  sudo docker compose run --rm --no-deps --entrypoint tar app -C /data -czf - . > "encore-data-$(date +%F).tar.gz"
  sudo docker compose start app

Храните копию в закрытом месте. Для обновления замените файлы приложения,
сохранив .env и том encore-data, затем снова выполните docker compose up -d --build.
При смене домена заново распечатайте QR. При том же домене и сохранённом томе
коды столиков сохраняются.
